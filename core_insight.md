# The Core Insight

## Three human principles

```
I AM LAZY
I WANT MONEY
I AM AN IDIOT
```

The system must work for someone who:
- Doesn't want to learn anything
- Wants to make money
- Can't be bothered with complexity

## What Muse can't do (but we can)

Muse can:
- Consume latest science about beauty
- Relate that to products
- Fill forms
- Check calendars
- Send messages

Muse CAN'T easily:
- Find historical prices of specific items over 10 years
- Know what's selling in Oldham right now
- Match personal skills to local economic opportunities
- Track which trades are undersupplied in a specific area
- Know what a used item is actually worth vs what's listed

## The approach

> What currently needs multiple layers of transformation for an agent → do that for it → display as MCP endpoints

## The core loop

```
I AM LAZY → Muse does it for me
I WANT MONEY → here's how to make it
I AM AN IDIOT → dead simple, no learning required
```

## Boring UK is the starting point

Because:
- Deterministic (forms have known outcomes)
- Grows with time (every verification adds data)
- Plugs into agent calendars (reminders, deadlines)
- Simple enough for anyone ("did it book my test? yes/no")
- Natural recurring interactions (tax, MOT, permits)

## The tradesmen opportunity

When Muse drops:
- Every tradesman gets a Muse agent
- The agent manages their business
- Xero plugs in finances
- Agents accept calls (commoditized)
- They need: what jobs are available locally? what can I repair and flip?

**UKGraph provides the economic ground truth.**

